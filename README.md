# Multiscale learning of dynamic gene network-driven phenotypic dynamics of single cells


![Overview](Overview.png)




## Getting Started
GRNvelo takes the input of time-series scRNA-seq data and outputs:
- infered the cell velocity in continuous time;
- infered the cell trajectory in continuous time;
- infered the cell growth;
- derived the internal gene regulatory network of the cell;
- acquired the latent time of the cell;
- acquired the perturbation trajectory.


## Requirements and Setup

```
conda create -n GRNvelo python=3.8.10
conda activate GRNvelo
pip install -r requirements.txt
```
## Examples
You can run the '' model/Train_GRNvelo.py '' file to get the training process and results on the Veres data.

## File comments in the "Model" folder
- model/AE: Reduce the dimensionality of high-dimensional data;
- model/TFvelo: The package used for drawing velocity fields and calculating pseudotime;
- model/Train_Generation.py: It combines three standalone codes (cell density estimation after dimensionality reduction, TC‑PINN, and MP‑PINN) into a single training script. Running this script trains all three components together in one unified process；
- model/DensityGeneration.py: Code for calculating the density of the data after dimensionality reduction;
- model/VelocityGeneration.py: Implements the TC‑PINN (Temporally-Consistent Physics‑Informed Neural Network), which learns cellular velocity fields from single‑cell data;
- model/VelocityRefine.py: Implements the MP‑PINN (Multi-Physics Informed Neural Network) which refines the raw velocity fields generated by TC‑PINN, enforcing physical constraints such as mass conservation or divergence‑free flow. This module is trained jointly with TC‑PINN and density estimation in the unified pipeline.
